# Haven house art shot list

Status: Round 1 done on 2026-10-02. Round 2 not started.

The homepage house is built from painted images that code layers and animates: depth between layers, light that follows the visitor's clock, window glow, and small cut-out props (pot steam, a breathing cat, a book that opens). The paintings themselves do not move.

## Rules for every image

- Attach the chosen house, [option 1](art/round-1/house-day-option-1-chosen.webp), to every Round 2 prompt as an edit source or style reference.
- For R2-01 and R2-02 use the tool's **edit** mode on option 1. Every object must stay in the same place, or the day-to-night blend wobbles.
- Highest resolution available, PNG. Option 1 arrived at about 1122 × 1402; an upscaled version is wanted for large screens.
- No text in images, no children's faces, plain light background where possible.
- Generate four of each and name files by prompt, for example `R2-07-3.png`.

## Round 1: style test (done)

Storybook gouache won. Option 1 (sage armchair, lilac throw, green gingham kitchen) was chosen for the calmest palette and the closest match to the site's sage, lilac and terracotta. Options 2 to 4 are kept in `art/round-1/` for reference.
